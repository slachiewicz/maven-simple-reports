Maven Reports

This site contains reports about Apache Maven repositories.

Available Reports

  • Dependabot Pull Requests - Live dashboard of open pull requests and stale branches across Maven repositories (single-page app; queries the GitHub GraphQL API directly, so it asks you to sign in first)
  • Maven 4 Adoption - External GitHub projects using Maven 4 POM format, wrapper, or GitHub Actions (regenerated daily)
Contribute on GitHub: aschemaven/maven-simple-reports
